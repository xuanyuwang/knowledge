Preserved correctness issues and quirks

Mixed sent populations use MAX

Trigger: Behavioral and nonbehavioral hints occupy different conversations/users

Observed: Sent/conversation/user denominators are independent branch MAX values, not summed or union-distinct populations.

Boundary: Observed real baseline and refactor; preserved, not corrected.

Moment-based sent and followed can lack delivered actions

Trigger: Positive adherence annotation references a nonexistent action

Observed: Default sent includes it; both followed paths count it. Action mode excludes it only from sent.

Boundary: Observed real baseline and refactor; no qualifying-use redefinition.

Knowledge follows accept empty and unlinked action IDs

Trigger: event_type9 has empty/unlinked action_annotation_id

Observed: COUNT DISTINCT includes the empty string and IDs with no matching sent action.

Boundary: Observed baseline and refactor.

Metadata exclusion depends on nullable joins

Trigger: Exclusion LEFT JOIN uses IS NULL under join_use_nulls=false

Observed: Unmatched IDs are empty strings; both exclusion-only and combined filters return empty. Nullable joins yield intended filtered cohorts.

Boundary: Observed with explicit settings0/1 on local CH23.8.16; production connection settings were not inspected.

Action mode loses behavior-filtered populations

Trigger: Behavior filter supplied with action-based sent calculation

Observed: Action table has no behavior column, so the existing false filter removes sent groups.

Boundary: Observed baseline and refactor.

Agent attribution can separate sent from followed

Trigger: Delivered action agent differs from the adherence annotation agent

Observed: Action-mode recipient group has sent1/followed0; detector-only followed group is dropped by the sent-anchored LEFT JOIN.

Boundary: Observed baseline and refactor.

Conversation totals retain grouping multiplicity

Trigger: One conversation has actions attributed to two agents

Observed: Each agent group counts the conversation once and the response sums to2.

Boundary: Observed baseline and refactor.

Group/policy no-frequency per-user averages remain zero

Trigger: Group by GROUP and POLICY with frequency unspecified

Observed: Group-level per-user averages remain zero because grouped conversion derives its denominator from time buckets, which no-frequency reads omit. Top-level rates retain the original values. Both delivery modes are characterized by full-RPC assertions.

Boundary: Observed on original and extracted production; preserved, not corrected.
