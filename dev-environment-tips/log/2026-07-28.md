## Details

The config's `deployment.k8sCluster` identifies the ClickHouse environment, but the ClickHouse database name is not always directly represented in config. The skill therefore resolves the database from the live `system.databases` catalog after AWS authentication. Credentials remain in process memory and are passed to ClickHouse only through `CLICKHOUSE_PASSWORD`.

For PostgreSQL, app DB metadata comes from `deployment.prodDbConnArn` / `deployment.sqlConn`, while auth DB metadata comes from `authConfig.authDbConnArn`. The skills preserve `cresta-cli` read-only agent safeguards and convert its in-memory URI to `PG*` environment variables before executing `psql`.
