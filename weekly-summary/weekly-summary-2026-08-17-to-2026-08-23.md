## Problems and Lessons

- Merged configuration and a green sync workflow are not sufficient evidence of runtime enablement. Global rollouts need effective-state read-back and protection against later full-object writers.
- Feature flags whose names sound similar can control independent behavior. CLO selector availability and materialized-view query routing must be rolled out and verified separately.
- Read-time enrichment must not become a hidden authorization, visibility, identity, or calculation change. Each consumer needs its existing semantic gate preserved explicitly.
- Reporting API reuse does not automatically reduce request count or complexity. The decision must include result grain, authorization, caching, failure isolation, and UI loading behavior.
- Destructive remediation should be preceded by exact formula simulation, including secondary effects outside the initially reported metric.
- Infrastructure CI failures should be diagnosed as such and rerun without weakening product checks or changing correct code to accommodate ephemeral runners.
