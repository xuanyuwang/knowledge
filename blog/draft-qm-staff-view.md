Quality management of call center involves

1. evaluating

2. monitoring/tracking

3. improving

It's a full cycle.

Evaluating

- set up criteria
- evaluate against criteria
  - ideally, should auto evaluate
  - in fact, there has to be manual evaluation
  - in reality, should be auto evaluate and manually calibrate

Difficulties:
- criteria versioning: a criterion will be updated for sure. It could be in many ways. And therefore all versioning related problem.
  - what the score mean: for example, greeting, from "hi" to a full intro of agent himself
  - score options: for example, now a criteria could be N/A
  - criteria weight

Monitoring/tacking

Reporting the existing evalaution data in multiple ways.

Difficulties

- data size: agents x calls x criteria. it can take 1 minutes to finish a query
- data sourcing: when there are multiple DBs, syncing between DBs
