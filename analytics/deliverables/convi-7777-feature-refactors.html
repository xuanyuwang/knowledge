Scope and review outcome

Source review and real ClickHouse characterization support the covered behavior equivalence. All tests PRs consolidate real-data tests into seven existing RPC suites, update generated BUILD targets, and delete 41 obsolete SQL snapshots plus redundant runnable suites. Each refactor PR is based on its own tests branch; all five stacks target main independently.

The extracted queries preserve feature-specific evidence grain, metadata filters, row attribution, time grouping, legacy distinct counts and denominators. The new Assistance Usage API is not integrated. The prior API-reuse commit remains removed.

Expanded GenAI RPC coverage caught a metadata column-naming regression in the extraction; explicit projections restore the original response, and the unchanged tests pass after the correction.

Review recommendation: review each tests PR first, then use its construction report to inspect the extraction. These PRs are ready for review; CI and your review remain outstanding. The existing population PR stack is unchanged.

Correctness quirks preserved for separate decisions

  • Metadata exclusions can drop eligible rows with no excluded annotation under default nonnullable LEFT JOIN semantics. Tests characterize this behavior; these refactors do not correct it.
  • Feature eligibility and denominators differ: KB/Suggestions retain source/developer event rows; Hints uses legacy MAX across hint families; GenAI retains different per-bucket and response user denominators.
  • Guided Workflow can count an empty session ID after its document/type gates. Summary requires matching generation and copy on conversation, start time and agent.

Each report records concrete triggers, expected outcomes, and remaining coverage limits. None of these observations is a production volume estimate.
