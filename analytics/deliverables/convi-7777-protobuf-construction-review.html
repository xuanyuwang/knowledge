A dedicated conversation assistance metric

The protobuf now defines a dedicated API for the adjacent Assistance Used leaderboard column and the existing chart trend. It returns eligible and assisted conversation counts with explicit Agent, Team, and overall semantics, plus optional conversation and agent feature-use details for verification.

Purpose and current scope

TriggerAgent/Team leaderboards and the Assistance Used chart request the new metric.
InputStandard eligibility filters, start-time range, grouping, frequency, and bucket metadata.
OutputMatching denominator and assisted counts. Multiple feature uses do not multiply a conversation's assisted count for an agent.
Current stageProtobuf and generated Go only. The October 12 opt-in implementation is superseded; backend and Director still need replacement.
